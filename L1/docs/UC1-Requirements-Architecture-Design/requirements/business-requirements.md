# Business Requirements — Online Shopping System

Source: retail company brief (USE CASE 1). These are the business-level statements before AI-assisted conversion into technical requirements (see `technical-requirements.md`).

| ID | Business Requirement |
|---|---|
| BR-01 | Customers can browse a catalog of products, view details, and search for items. |
| BR-02 | Customers can add products to a cart and modify quantities before checking out. |
| BR-03 | Customers can place an order and track its status. |
| BR-04 | Customers can pay for their order securely. |
| BR-05 | Customers can register, log in, and manage their profile and addresses. |
| BR-06 | The system must remain responsive and available during peak shopping traffic (e.g., sale events). |
| BR-07 | The system must protect customer payment and personal data in line with applicable regulations. |
| BR-08 | The business must be able to release changes to one part of the store (e.g., promotions) without risking downtime in checkout. |
